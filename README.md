# Parag (पराग): making pollination visible

Website for **Parag**, a smartphone-first AI platform that makes crop pollination visible for Indian smallholder farmers.

Farmers scan their flowering field with a phone; Gemini estimates pollinator activity against crop benchmarks, gives voice advice in Marathi or Hindi, and books verified nearby beekeepers to rent hives. Built on Google AI and Google Cloud.

Live at **https://www.paragpollinators.com**

## Stack
Static HTML/CSS served with GitHub Pages. Custom domain set in `CNAME`.

## Local preview
```sh
python3 -m http.server 8000
```
Then open http://localhost:8000.
